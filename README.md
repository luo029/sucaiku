# 素材库

> 读书所得，随手而藏；他日行文，或可一助。

库分三藏：

| 仓库                    | 所藏                                         |
| --------------------- | ------------------------------------------ |
| `sucaiku`             | 本体也。页面陈设、样式脚本皆在焉，布于 GitHub Pages，不烦构建，启户即见 |
| `luo029/sucaiku_data` | 数据之府也。条目篇章、标签类目咸萃于斯                        |
| `sucaiku_pictures`    | 图绘之笥也。所收梗图、所上传之影像皆归之                       |

## 叙

余性喜读说部，自稗官野史以逮今人小说，靡不涉猎。每见佳句，如获珠玉；遇可惊可喜之段落，辄掩卷而录，恐其旋得旋失也。市井间有所谓梗图者，滑稽诙谐，足以破闷，亦并收之。日积月累，遂成此库。非敢云著述，聊以备他日操觚之资耳。

库中之制：数据先存于浏览器 `localStorage`，复可假 GitHub API 同步于 `luo029/sucaiku_data`，故虽换机易地，而所积不亡；图片则归 `sucaiku_pictures`，随取随用，如携书箧而行。

昔人云「积学以储宝」，余于文字亦云。若夫闲窗无事，启库纵观，则旧日所读、所笑、所叹者，历历在目，亦一乐也。
